# P005: a fraction with zero below

`n/d`, written with no space, is a real number, the fraction. With `d`
zero it is no number.

## Example

    fn f() -> y: rational { 1/0 }          // error[P005]

## Fix

Write the number meant. To divide, write the reals with spaces and
points, `1.0 / x`: a division, which has no value at zero.
