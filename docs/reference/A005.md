# A005: a contract claim a function that fits breaks

An `impl` makes a contract's claim one about the functions that fit it.
At a point, with those functions, the claim is false: the function fits
the contract's types but not its claim.

## Example

    contract Monotone<T: Number> { fn f(x: T) -> y: T; claim rises(a: T, b: T) = !(a <= b) || f(a) <= f(b); }
    fn fall(h: Real) -> d: Real { 0.0 - h }
    impl Monotone<Real> for fall;      // finding[A005]: false at a = 0, b = 1

## Fix

Fix the function, or do not say it fits the contract.
