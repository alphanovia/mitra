# P010: a part no file of the model declares

A `use` reads a part. A part the model's file does not declare is read
from `<part>.mitra` beside it (the CLI), and `use std::core::…` from
Mitra's own standard model, shipped in the binary. A part found in
neither is no part: Mitra does not guess one.

## Example

    subject calc {
        use geom::Point;
    }
    // error[P010]: no part `geom`: no file of the model declares it, and there is no `geom.mitra` beside it

    use std::kore::Option;
    // error[P010]: no part `std::kore`: Mitra's standard model has `std::core`

A file read for a part must declare it:

    // error[P010]: `geometry.mitra` declares no part `geometry`: a part read from a file is declared in it

## Fix

Spell the part as declared, or put it in `<part>.mitra` beside the
model. Mitra's standard model has `std::core` (`Option`, `Result`).
