# V005: a review of nothing a review can name

A review says that a proposition holds, or not: a claim, a rule, a
require or an ensure, by its path, or a tied item, which is a review of
its ties. A part, record or function that is not tied is no proposition.

## Example

    review stone::speed holds by "human:ana";   // error[V005]: `stone::speed` is not tied
    review stone::nothing holds by "human:ana"; // error[V005]

## Fix

Name a claim, rule, require or ensure, or tie the item first.
