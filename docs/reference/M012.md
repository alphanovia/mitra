# M012: a proof that does not show its rule

A proof reads opinions of its rule's premises and gives an opinion of
the conclusion: it must check to that type. And since an opinion can argue
against its proposition, or come from a conflict, the proof is also run
once, on all it reads taken true, and must give the conclusion true
(`docs/model.md`, choice 5).

## Example

In the illustrative syntax of `docs/model.md`:

    rule lands: drop::falls |- drop::slow by reductio(drop::falls);    // error[M012]

## Fix

Write a proof that argues for the conclusion, or drop it: the rule is then
assumed, and stays a leaf.
