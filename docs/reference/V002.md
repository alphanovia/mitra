# V002: a measurement through no tie

A measurement is of the real system, so it is always through a tie:
each function it names is tied, or its part is. A row of what a function
gives with no tie is an example of the model (its spec), and a run of the
model on itself is simulation: neither is evidence.

## Example

    tie calc::div at src/lib.rs/div;
    measurement of calc::mul (6, 2) -> 12     // error[V002]: `calc::mul` is tied to nothing

## Fix

Tie the function or its part to where it is, `// mitra: implements
calc::mul` above it in the code; or write the row as an example of the
function.
