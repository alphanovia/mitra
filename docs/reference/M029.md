# M029: an ensure of a part holding parts that rests on what is not its parts' ensures

What a part holding parts ensures rests only on the ensures of its own
parts and on its own requires: the whole is explained by its parts.

## Example

    subject C { ensure c: "c"; }
    subject A {
        ensure a: "a" from (C::c);
        subject B { ensure e: "e"; }
    }
    // error[M029]: `C::c`: `A` holds parts, and its ensures rest only on
    // its parts' ensures and its own requires

## Fix

Rest `a` on `B::e`, or write `require c: C::c;` in `A` and rest on `A::c`.
