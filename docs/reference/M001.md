# M001: a name is not a word

A name is letters, digits and `_`, and does not start with a digit. Then a
path reads one way: `stone::drop::falls` is the claim `falls` of the
function `drop` of the part `stone`, and nothing else.

## Example

In the illustrative syntax of `docs/model.md`:

    require still air = "no wind";    // error[M001]: `still air` is not a word

## Fix

Write it as a word: `require still_air: "no wind";`.
