# X004: an output the model cannot compute from the inputs

To say what a measured output should be, the model runs the function at
the inputs, through its calls. A function it calls has no body and no
value at the point it is called: the measurement does not give what it
gave, and it has no example there.

## Example

    fn speed(h: Real) -> v2: Real { 2.0 * 9.81 * h * light() }
    // measured: speed at (5.0) gave 98.0, with no value of light()
    // finding[X004]: at (5.0), `stone::speed` needs what `sun::light`
    // gave, which nothing gives: measure it as an input

## Fix

Give what that function gave as an input, `sun::light::w = 2.0`.
