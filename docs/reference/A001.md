# A001: a body that breaks a claim

A function's claim is read with its body in place of what it gives: it
must be true at every value of what the function takes. Agree found a
point where it is false, or has no value (a division by zero, say: a
claim with no value does not hold), and `Exact` confirms it there. A
function that takes nothing has one point, `()`.

## Example

In the text of `docs/syntax.md`:

    fn speed(h: Real) -> v2: Real { 2.0 * 9.81 * h } where {
        claim slow: !(h <= 20.0) || v2 < 300.0;   // finding[A001]: the body breaks claim `slow` at h = 20.0
    }
    fn z() -> y: Real { 1.0 / 0.0 } where {
        claim pos: 0.0 < y;   // finding[A001]: the body breaks claim `pos` at (), where it has no value
    }

## Fix

Fix the body, or the claim: one of them says what the system does not.
