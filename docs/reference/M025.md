# M025: a range type that holds no number

A range type, `0..=9`, is the whole numbers from its low end to its high
end, both in: an `Int` that is checked. One whose low end is above its
high end holds no number, so nothing could be given or taken there.

## Example

    fn f(a: 9..=0) -> b: Int { a }
    // error[M025]: `a: 9..=0` holds no number: a range is written low end first, `0..=9`

## Fix

Write the low end first: `0..=9`.
