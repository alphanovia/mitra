# M005: a body not of the type its function gives

A body reads what its function takes and must check to the type the
function gives.

## Example

    subject s {
        fn g(x: Int) -> y: Real { x + 1.0 }
    }

    error[M005]: the body is not of the type of `y`
     --> s::g
      |
      | x + 1.0
      | ^^^^^^^ `x` is Int and `1.0` is Real
      = note: `+` takes two numbers of one type: Int, Real, or one `T: Number`

The message is shaped as M006's: the body, its innermost part with no
type underlined, what that operation takes, and a help when a whole
number is the cause; else `this is Real` and `note: it should be Int`.

## Fix

Write a body of the type the function gives, or give another type.
Mitra converts no number.
