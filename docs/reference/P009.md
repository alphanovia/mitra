# P009: a value whose type cannot be told here

`None` is an `Option<T>`, but which `T`? Mitra reads it from where the
value goes: a function's result, a field, an argument, the other side of
`==`. Where nothing says, the value has no type, and Mitra does not guess
(Rust's E0282). The same holds for a generic record whose fields do not
tell its parameters, and for `[]`, a sequence holding no value: of which
type?

## Example

    fn f(x: Int) -> y: bool { None == None }
    // error[P009]: the type of `None` cannot be told here: use it where a
    // value of its type is wanted, as a function's result, a field, an
    // argument, or beside `==`

    fn g(x: Int) -> y: bool { [] == [] }
    // error[P009]: the type of `[]` cannot be told here: …

## Fix

Use the value where its type is wanted: `None == f(x)` where `f` gives
an `Option<Int>`, or give it to a function that takes one.
