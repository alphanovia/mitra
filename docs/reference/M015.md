# M015: an example not of its function's types

A function's examples say what it gives at some points, each row
`(takes…) -> gives`. A row has one value for each name the function
takes, in order, each of its type, and gives a value of the type the
function gives. A row is checked only when the function's types are known
(M003 first).

## Example

In the illustrative syntax of `docs/model.md`:

    fn speed(h: Real) -> v2: Real = 2 * 9.81 * h {
        examples { 5.0 -> 98.1, (5.0, 1.0) -> 0.0 }    // error[M015]: example 1
    }

## Fix

Give the row as many values as the function takes, of their types, and a
value of the type it gives.
