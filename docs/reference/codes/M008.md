# M008: a proposition of another part

Parts meet only through requires: a rule or a list names only the
propositions of its own part. Else what one part assumes of another would
be used with no proposition to blame for it.

## Example

In the illustrative syntax of `docs/design/model.md`:

    subject stone {
        rule bright: air |- sun::shines;    // error[M008]: `sun::shines` is the sun's
    }

## Fix

Require it, and name the require: `require light: sun::shines;`, then
`light`.
