# A020: a failure a body turns into an ordinary value

A body calls a function that gives a `Result`, matches its `Err` into a
value that is no failure, and gives a type that holds no failure
(finding 45 J6). A fallback can be meant; it must then be said: an
example where the callee fails (a `given` of its `Err`), or a claim that
calls it, answers the finding.

## Example

    fn screen(t: integer) -> ok: bool { match classify(t) { Ok(b) => b, Err(_) => true } }
    // finding[A020]: `Guard::screen` calls `Llm::classify`, which can
    // fail, and gives bool, which has no failure: the `Err` arm gives
    // `true`; give an example where `Llm::classify` fails, or a claim on it

## Fix

Carry the failure in what the function gives (a `Result`), or write the
example or claim that says what happens when the callee fails.
