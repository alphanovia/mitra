# A014: an example whose run calls for a value nothing gives

An example is one run (finding 39 B). On its way, the run called a
function with no body at arguments where nothing gives its value: the
example has no `given` for it, and none of the function's own examples
is at those arguments. The example fails: a run in a world the example
does not state is no run at all.

## Example

    fn route(n: integer) -> r: integer { if n > 10 { small(n) } else { big(n) } } where {
        examples { given Disk::small(3) -> 30 when (3) then 30 }
        // finding[A014]: example 0: fails: no value for `Disk::big(3)`: the
        // run calls it, and nothing gives it there; give it in the example
        // (`given Disk::big(3) -> …`), or give `Disk::big` a body
    }

Here the test is the wrong way round (`n > 10` for `n < 10`): the run
takes the other branch, and asks the world for what the example does not
give. The given it does state is never called: A015.

## Fix

If the run is meant to take this way, give the value in the example. If
not, the body is wrong. A function with a body never needs a given.
