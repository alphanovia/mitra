# A025: a condition on opaque results a claim needs, and no claim states

`mitra search` ran an example with the results of the functions with no
body left unknown, and found results on which a claim breaks. No claim of
those functions rules them out: the model needs a promise it does not
state.

## Example

    environment Clock { fn now() -> t: integer; }
    fn left(deadline: integer) -> l: integer { deadline - Clock::now() } where {
        claim within: l <= deadline;
        examples { given Clock::now() -> 3 when (10) then 7 }
    }
    // finding[A025]: claim `within` holds on the runs of Timer::left::example 0
    // only if not (`Clock::now()` gives -1): no claim of a function with no body says so
    // (gone with `claim after_start: t >= 0;` on `now`)

## Fix

State the promise as a claim of the function with no body, or change the
body so that it does not depend on it.
