# A021: an input a body never reads

A function with a body takes an input its body never reads (finding 45
J6), as Rust warns of an unused variable: what the input is for is only
in words, a comment or a name. A name starting with `_` says it is meant.

## Example

    fn post(store: integer, n: integer) -> r: integer { n + 1 }
    // finding[A021]: `store` is taken by `Server::post` and never read by
    // its body: what it is for is only in words; name it `_store` if that
    // is meant

## Fix

Read it where it matters, drop it, or name it `_store`.
