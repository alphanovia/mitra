# A012: a value written in a row that breaks its record's claims

A record's claims say what each of its values holds. Mitra checks them
where a value enters the model: what a function with a body gives
(A001, A007), and each value written in a row: an example's inputs and
output, what `given` says a function with no body gave, the arguments
of `when` and of the calls `then` lists. A record inside another, in a
sequence or in a variant is checked too. A value that breaks a claim is
this finding; one the claim cannot be decided of is A007.

What takes a record counts on its claims: they are checked where it
was made, so a function's claims are read where they hold.

## Example

    subject Span {
        record { lo: integer, hi: integer } where { claim ordered: self.lo <= self.hi; }
        fn width_of(s: Span) -> w: integer { s.hi - s.lo } where {
            examples { (Span { lo: 3, hi: 1 }) -> -2 }
            // finding[A012]: example 0: `s` = Span { lo: 3, hi: 1 } breaks
            // record claim `Span::ordered`
        }
    }

## Fix

Write a value the claim holds of, or, if such values exist, loosen the
claim.
