# A007: a comparison not decided

Agree did not decide a comparison: by bounds over all of what it reads,
the claim may be true or false, and no point it tried makes it false. Or
the model has no value where it needs one (a function with no body and
no row there). Or the comparison reads an opaque record (`record Key;`):
bounds would read it as one value, so agree reads none, and no value of
it is written to try. For claims together: no point tried keeps them
all, and nothing shows they clash. The comparison is neither shown nor
refuted; it says how far agree looked (`Settings::points`), and when
bounds stopped at their own budget (simulation's `Budget`), it says that
too, instead of a plain "not decided".

## Example

    fn speed(h: rational) -> v2: rational { 2.0 * 9.81 * h } where {
        claim slow: !(h <= 20.0) || v2 < 400.0;
        // finding[A007]: claim `slow`: unknown, not decided by bounds over
        // all of what it reads, nor at 64 points
    }

When bounds stop at their budget (finding 24):

    // finding[A007]: claim `c`: unknown, not decided by bounds, which
    // stopped at the depth budget, nor at 64 points

## Fix

Nothing may be wrong. Give an example at a point that matters, a rule
with a proof, or evidence; or try more points.
