# A019: an enum case no body makes

Bodies of the model make some cases of an enum, and none makes this one
(finding 45 J6): a promise may rest on it (a receipt that says a message
was read) while nothing in the system ever sends it. An enum no body
makes at all, an environment's enum, and one a function with no body
gives (the world makes its cases) are left alone. A finding, not an
error: the model is still read.

## Example

    subject enum Receipt { Received, Delivered, Read }
    subject Store {
        fn post(n: integer) -> r: Receipt { if n > 0 { Receipt::Received } else { Receipt::Delivered } }
    }
    // finding[A019]: `Receipt::Read` is never made: bodies make
    // `Receipt::Received` (in `Store::post`), `Receipt::Delivered` (in
    // `Store::post`), and none makes `Receipt::Read`

## Fix

Make the case where the system does, or drop it.
