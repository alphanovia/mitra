# A015: a given an example's run never calls

Everything an example states is used (finding 39 B). A `given` the run
never calls, at those arguments (`_` any), is a finding: the run did not
go the way the example says, or the given is left over. A `given` of a
function with a body is refused before (M022): its body is read.

## Example

    examples { given Disk::small(3) -> 30 when (3) then 30 }
    // finding[A015]: example 0: `Disk::small(3)` is given but never
    // called: the run calls `Disk::big(3)`

## Fix

Drop the given, or fix the body that should have called it. The finding
lists the calls to functions with no body the run made.
