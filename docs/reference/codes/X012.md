# X012: a link, or a piece said only in words, no voice reviewed

An ask, not a fault. A link is only the model's word until someone
reviews it: an ensure's `from` list, that those pieces together give
it. Until then Mitra takes it as written, with little weight (the
voice `assumed:link`, `[numbers] link`), and what rests on it is
**assumed**, not explained. An ensure said only in words, with nothing below it, likewise. A
require from an ensure is not asked for: it is that ensure, named. `mitra explain`
lists each one no review answers, with the line to write in the store
once reviewed, the links the most assumed statements rest on first. A review that fails answers it too: someone looked.

## Example

    ensure answers: "each message gets a reply" from (Harness::serve);
    // ask[X012]: Mitra takes that `assistant::Harness::serve` gives
    // `assistant::answers` as written, with no review: what rests on it
    // is assumed; review the link
    //  --> assistant::answers
    //   = help: once reviewed, write in the store
    //     `review assistant::answers from holds by "human:<name>";`

## Fix

Look at the link, then write the review in the store, `holds` or
`fails`, with your voice. For words a test shows, add
`seeing "test:name"`: the review counts while the test passes.
