# P001: a character that starts nothing

The text has a character no word, number, string or symbol of the
language starts with (`docs/design/syntax.md`). Also a `\` in a string that
escapes nothing.

## Example

    subject calc { # }                 // error[P001]: `#` starts nothing in the language

## Fix

Take it out, or put it in a string or after `//`. In a string, write
`\n`, `\t`, `\"` or `\\`.
