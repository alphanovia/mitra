# M028: a part holding parts that holds more than parts, requires, ensures and examples

A part that holds parts says what the whole does: its requires, its
ensures and its examples of the whole. Its records, functions, uses and
contracts belong to one of its parts.

A part whose inner parts hold only data (a record or an enum) is not
such a part: it keeps its functions, as a Rust module keeps its structs.

## Example

    subject A {
        fn f(x: integer) -> y: integer { x }
        subject B { ensure e: "e"; }
    }
    // error[M028]: `A` holds parts, and also a function: a part holding
    // parts holds only them, requires, ensures and examples; move the rest
    // into one of its parts

## Fix

Move `f` into `B`, or into a new part inside `A`.
