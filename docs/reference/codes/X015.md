# X015: a test tied to an ensure that failed

A test tied to an ensure (`// mitra: supports a::e`) failed. Mitra
assumes the test shows what it is tied to, so its failure counts
against the ensure: the ensure is contradicted, and blame may doubt the
run, the tie, or the code.

## Example

    finding[X015]: the test `tests::every_code_has_a_page`, tied to
    `codes::documented`, failed: it counts against it, assuming the test
    shows what it is tied to
     --> codes::documented

## Fix

Fix the code, or the test. If the test does not show the sentence,
move its `supports` comment to the ensure it shows.
