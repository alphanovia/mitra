# A009: an input of a model example no output reads

An example of the model gives inputs, and agree computes each output from
them, through calls. An input is read when it is what an output's
function takes, a value of the world (what a function with no body gives)
that the computation calls for, or what that function takes. Any other
input is given and read by nothing: what a function takes where another
calls it is computed there, not given. Nothing is dropped quietly.

## Example

    subject stone {
        fn speed(h: rational) -> v: rational { 2.0 * h }
        fn half(h: rational) -> v: rational { speed(5.0) / 2.0 }
    }
    examples {
        (stone::half::h = 1.0, stone::speed::h = 1.0) -> stone::half::v = 5.0
        // finding[A009]: `stone::speed::h` is given and no output reads it:
        // the model computes what `stone::speed` takes where it is called
    }

The same holds of a `given` row: a function with no body given and
called by no output.

    examples {
        given Sun::light() -> 2.0, Sun::hour(3) -> 4 when Stone::heat(5.0) then 10.0
        // finding[A009]: `Sun::hour` is given and no output reads it: no output calls it
    }

## Fix

Drop the input, or state an output that reads it: an example of the
model gives what its outputs read.
