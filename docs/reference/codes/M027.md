# M027: an enum or a record declared so that no value fits it

An enum with no variant has no value. A type parameter that nothing a
record or enum holds uses says nothing (Rust's E0392). An enum that
holds itself in every variant, `enum Loop { More(integer, Loop) }`, or a
record that holds itself, would need a value that never ends. A tree
is fine: `enum Tree { Leaf, Node(Tree, integer, Tree) }` has `Leaf`,
which holds no `Tree`.

## Example

    enum Never {}
    // error[M027]: `Never` has no variant: no value is of it
    record Box<T> { n: integer }
    // error[M027]: the type parameter `T` is used by nothing it holds: Rust's E0392
    enum Loop { More(integer, Loop) }
    // error[M027]: `Loop` holds itself in every variant: no value of it ends; give it a variant that does not hold it, as a tree's `Leaf`

## Fix

Give the enum its variants; remove the parameter or use it in a field;
give a tree a variant that does not hold it (`Leaf`, `Nil`). Unlike
Rust, no `Box` is needed: a model has no memory layout.
