# M027: an enum or a record declared so that no value fits it

An enum with no variant has no value. A type parameter that nothing a
record or enum holds uses says nothing (Rust's E0392). A record or enum
that holds itself, `enum List { Nil, Cons(integer, List) }`, would need a
value that never ends: core2 has no trees yet (finding 3).

## Example

    enum Never {}
    // error[M027]: `Never` has no variant: no value is of it
    record Box<T> { n: integer }
    // error[M027]: the type parameter `T` is used by nothing it holds: Rust's E0392
    enum List { Nil, Cons(integer, List) }
    // error[M027]: `List` holds itself: a value of it would never end

## Fix

Give the enum its variants; remove the parameter or use it in a field;
for a list, use a fixed number of fields until trees come.
