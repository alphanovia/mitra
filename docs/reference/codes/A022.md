# A022: a route counting a function the run never calls

A route claim counts calls of a function that no body reachable from
the claim's function calls. `never` and `at most` then always hold, and
`once` never: the claim says nothing of the run.

## Example

    fn serve(m: Message) -> r: Reply { Reporter::report(m) } where {
        claim quiet: never Tool::call(_, _);
    }
    // finding[A022]: `Tool::call` is counted, and no body `serve` reaches calls it

## Fix

Count a function the run calls, or drop the claim.
