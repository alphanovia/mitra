# A005: a contract claim a function that fits breaks

An `impl` makes a contract's claim one about the functions that fit it.
At a point, with those functions, the claim is false, or has no value:
the function fits the contract's types but not its claim. The points
tried include the constants of the functions the claim calls.

When every impl of the contract, two or more, breaks the claim, it is
said once, at the contract, listing where each breaks it: the claim
itself is then the first suspect.

## Example

    contract Monotone<T: Number> { fn f(x: T) -> y: T; claim rises(a: T, b: T): !(a <= b) || f(a) <= f(b); }
    fn fall(h: rational) -> d: rational { 0.0 - h }
    impl Monotone<rational> for fall;      // finding[A005]: false at a = 0.0, b = 1.0
    fn rise(h: rational) -> d: rational { h }
    impl Monotone<rational> for rise;

With `fall` and `inv` its only impls, it is said once, at the contract:

    fn inv(x: rational) -> y: rational { 1.0 / x }
    impl Monotone<rational> for inv;
    // finding[A005]: every impl of `Monotone` breaks it: `s::fall` false at a = 0.0, b = 1.0;
    // `s::inv` no value at a = 0.0, b = 0.0; the claim, or every impl, is to look at
    //  --> Monotone::rises

## Fix

Fix the function, or do not say it fits the contract. Said at the
contract: check the claim first.
