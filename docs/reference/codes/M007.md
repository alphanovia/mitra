# M007: a name that names no proposition

A rule's premises and conclusion, and each list of an ensure, name
claims, rules, requires or ensures. Not a part, a record or a function, and
not a path that names nothing.

## Example

In the illustrative syntax of `docs/design/model.md`:

    rule slows: drop::fell, speed::slow |- drop::slow;    // error[M007]: no `drop::fell`

## Fix

Name a proposition that is declared, or declare it.
