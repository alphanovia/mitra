# X009: a budget of steps or depth reached

`Exact` and `Ranges` count the calls of one computation, and the levels
of the bodies active at once. Each has a budget, a setting
(`simulation::Budget`: 100,000 calls, 1,000 levels). Past one, the
computation stops with no value, and the reading says which budget and
where: explain gives this finding and decides nothing there; agree says
unknown (A007) with the same words.

## Example

    // 40 functions, each a body 1,000 levels deep, calling the next:
    finding[X009]: at (1), `s::f39`: the depth budget, 1000 levels of
    bodies through calls, reached at `s::f12`

A set's condition that calls a function is read at each point the same
way: a point not read to its end leaves it unknown whether that point is
in the set, and the `all` or `any` over it learns nothing from its
points:

    finding[X009]: `all p in (a: 0..10) where s::f(a) < 5: correct(s::g, p)`:
    the condition of the set (a: 0..10) where s::f(a) < 5 was not read to
    its end at (0) (a budget reached, or a call with no value there): whether
    that point is in it is not known, so it is given nothing from its points

## Fix

Raise the budget, if the computation is meant to be that long; else
write shallower bodies, or a function with no body and examples.
