# R012: a field whose Rust type holds values its model type does not

Types are checked, never converted: every value of the Rust field must
be a value of the model's type. `i64` or `u8` fits `integer`, `String`
fits `[~char]`, `Vec<T>` and `[T; N]` fit `[T]`, `Option` and `Result`
fit std's, a tuple a tuple, and a struct tied to a record fits that
record. A record tied to an enum, or the other way, is listed too, as
is a variant holding another number of values.

## Example

    subject Count {
        record { n: integer }
    }

    // mitra: implements Count
    pub struct Count { pub n: String }
    // finding[R012]: field `n` of struct `Count` is `String`: not every
    // value of it is of `integer`

## Fix

Give the model the type the code holds, or the code the type the model
says. A struct the field names is tied to its record with
`// mitra: implements`, or `at "…"` in the model.
