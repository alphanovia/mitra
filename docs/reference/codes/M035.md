# M035: a route claim of a function with no body

A claim of a function with no body reads the calls of a run
(`calls(f)` or a route form). A function with no body has no run in the
model: its claims are promises about what it gives.

## Example

    fn screen(m: Message) -> v: Verdict where { claim once: once Llm::inference(_, _); }

## Fix

Put the route claim on a function with a body that calls it, or give
`screen` a body.
