# X016: a measured point at which a loop never ends

Explain reads the model at each point a test measured. At this one, an
`until` came back to values it had already carried, so it never ends
(as A013 for agree): the model has no value there, and the measurement
decides nothing.

## Example

    fn halve(n: integer) -> k: integer { until(k: n, k <= 1) { k } }

    // measured: n = 4, k = 1
    finding[X016]: at (4), `s::halve`: the `until` in `s::halve` never
    ends: what it carries, 4, came back after 1 turn

## Fix

The model's loop forgets a step that the code takes: the code ended at
this point. Fix the loop's block.
