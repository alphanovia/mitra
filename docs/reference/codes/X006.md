# X006: judging stopped before it was done

Explain applies every rule again until nothing changes. It stopped at
the most rounds its settings allow (`Settings::rounds`), or left a rule
out because its premises rest on more sets of takings together than
`Settings::rests` allows, counted once only the smallest sets are kept
(two premises resting on the same three tests give 3 sets, not 9): what follows further is not said, and some
verdicts may be missing support or contradictions.

## Example

    // explain with Settings { rounds: 0, .. }
    // finding[X006]: judging stopped after 0 rounds (`Settings::rounds`):
    // what follows further is not said

## Fix

Raise `rounds`: a chain of rules needs one round a link. For a rule
left out, raise `rests`, or split the rule (an ensure from fewer
claims): each way to have every premise is one more set to compare.
