# M032: a proof written as its step alone that no proof, or two, fill in

`by ponens`, `by tollens`, `by cases`, `by instance`, `by witness`,
`by intro` and `by reductio` name one step of a proof and leave out its
arguments: Mitra fills them in from the rule's premises, each as it is
or negated, in each place the step takes. It must find exactly one
proof the checker takes. None, and the rule is not shown; two, and
Mitra would have to choose which premises the proof rests on.

## Example

    subject calc {
        fn half(n: 0..=9) -> h: 0..=9 { n / 2 } where {
            rule up: correct(half, (4)) |- correct(half, (5));
            rule five: correct(half, (4)) |- correct(half, (5)) by ponens;
            rule some: correct(half, (1)), correct(half, (1)) |- any x in (n: 0..5): correct(half, x) by witness;
        }
    }
    // error[M032]: no `ponens` of the premises shows `five`: write the proof in full, `by ponens[rule, post](…)`
    // error[M032]: `by witness` shows `some` 2 ways: `by witness[any x in (n: 0..5): correct(calc::half, x)](0, point(1))`, `by witness[any x in (n: 0..5): correct(calc::half, x)](1, point(1))`; write the one you mean

`five` does not list `half::up` among its premises, so no ponens has a
rule to apply. `some` writes the same premise twice in place, and
either is a witness.

## Fix

Add the premise the step needs, or write the proof in full: for two,
copy the one you mean from the message.
