# R013: a Rust form Mitra cannot write yet

The tie's struct or enum has a form the model has no way to say yet: a
generic struct or enum, a tuple struct, a variant with named fields,
`f32` or `f64` (`rational` is exact, and nothing converts), or a map or
a set. The tie is then not checked, for or against.

## Example

    // mitra: implements Belief
    pub struct Belief { pub belief: f64 }
    // finding[R013]: field `belief` of struct `Belief` is `f64`: Mitra
    // has no form for a float yet: `rational` is exact, and nothing
    // converts

## Fix

None in the model yet: the finding says where the tie goes unchecked.
A variant with named fields can hold its values in order instead,
`V(T, U)`, and a tuple struct can name its fields.
