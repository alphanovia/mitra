# A004: claims no value keeps together

A function's claims, all together (one claim or more), are false
whatever it takes and gives: no function can keep them. Agree sees it by
bounds, or by trying every value of a finite domain (truths, records of
them). Bounds read each claim on its own ranges, so they see a claim
false whatever the values, not two that only clash on one value
(`0 < v` and `v < 0` are not seen). This comparison fails at no point.

Agree also looks for a value that keeps them all: the function's
examples first, then what its body gives, then candidates. When none is
found and nothing shows they clash, it is unknown (A007).

## Example

    fn drop(h: rational) -> v: rational where {
        claim falls: 0.0 <= v;
        claim never: 1.0 < 0.0;     // finding[A004]: no value keeps all its claims
    }
    fn lit(on: bool) -> off: bool where {
        claim a: off;
        claim b: !off;              // finding[A004]: no value keeps all its claims
    }

## Fix

One of the claims is wrong: drop it or fix it.
