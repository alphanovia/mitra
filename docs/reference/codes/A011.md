# A011: a call a row's `then` lists that the run does not make

A row's `then` may list, after the value, calls to functions with no
body: what the run does to the world. agree runs the row and keeps each
call such a function receives; a listed call the run never makes, with
those arguments (`_` any), is this finding. A listed call holds when the
run makes it at least once; calls not listed are not compared.

## Example

    environment Disk {
        fn write(path: [~char], body: [~char]) -> ok: ();
    }
    subject Notes {
        use Disk::write;
        fn save(n: [~char]) -> r: integer { if n == "" { 0 } else { write("a.txt", n); n.len() } } where {
            examples { when ("") then 0, Disk::write("a.txt", "") }
            // finding[A011]: example 0: the call `Disk::write("a.txt", "")`:
            // the run does not make it; it calls no function with no body
        }
    }

## Fix

Make the body call it, or take it out of `then`: the message lists the
calls the run made, in order.
