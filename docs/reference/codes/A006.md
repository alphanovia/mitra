# A006: an example of the model the model does not give

An example of the model gives inputs across parts and states outputs.
Through calls, the model computes an output that is not the one stated,
or no value. Or a value of the world the example gives (what a function
with no body gave) is not what that function's own example says at that
point: the example's value is read, and the two are compared.

## Example

    examples { (sun::light::w = 2.0, stone::speed::h = 5.0) -> stone::speed::v2 = 98.1 }
    // finding[A006]: `stone::speed::v2`: the model gives 196.2 at h = 5.0

    fn light() -> w: rational where { examples { () -> 850.0 } }
    examples { (sun::light::w = 900.0, stone::speed::h = 1.0) -> stone::speed::v2 = 17658.0 }
    // finding[A006]: `sun::light::w` against example 0 of `sun::light`: the model gives 850.0 at ()

## Fix

Fix the model, or the example.
