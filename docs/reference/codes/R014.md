# R014: a given no row follows

A test printed what the environment gave its run, with
`mitra::given!`, and printed no row after it. A given is the world of
the next row of its test (`mitra::check_eq!` or `mitra::check!`): with
no row, it measures nothing, and Mitra says so rather than drop it.

## Example

    #[test]
    fn warms() {
        let sun = FakeSun { light: 2 };
        assert_eq!(heat(&sun, 5), 10);
        // mitra: given Sun::light () -> 2
        // finding[R014]: `Sun::light() -> 2` is given and no row of its
        // test follows
    }

## Fix

Write the call with `mitra::check_eq!(heat(5), 10)`, after the
environment answered: the row is then
`measure given Sun::light() -> 2 when heat(5) then 10`.
