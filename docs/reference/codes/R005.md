# R005: a measuring test that did not run

A test with a `measures` comment is not in the `cargo test` report, was ignored, or its name matches several tests of the report.

## Example

    // mitra: measures calc::div (6, 2) -> 3
    #[test] #[ignore]
    fn div_by_two() { … }                // finding[R005]: ignored

## Fix

Run the test, give the report of every test of the revision, or rename one of the tests that share the name.
