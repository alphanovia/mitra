# M018: a function or record of another part, not used

A part calls another part's function, or names another part's record (in
a type, or making one), only through a `use` that reads it. The use makes
each link between parts visible, so that it can be blamed: a claim that
reads `light()` rests on the sun too.

## Example

In the illustrative syntax of `docs/design/model.md`:

    subject stone {
        fn speed(h: rational) -> v: rational { 2.0 * h * sun::light() }  // error[M018]: `sun::light` is of another part: `use sun::light;`
    }

## Fix

Add `use sun::light;` to the part, or `use sun::*;`.
