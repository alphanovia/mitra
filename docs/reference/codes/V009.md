# V009: a test tied to what is no ensure

`// mitra: supports a::e` above a test ties it to an ensure: what it
shows, said in words. A path that names no ensure of the model is
refused: a typo, or a claim, which a test measures with a row instead.

## Example

    // mitra: supports codes::documentd
    #[test]
    fn every_code_has_a_page() { … }
    // error[V009]: `codes::documentd` is no ensure: a test is tied to an
    // ensure, what it shows in words

## Fix

Name the ensure by its whole path. To measure a function, write the row
it saw: `// mitra: measures f (6, 2) -> 3`.
