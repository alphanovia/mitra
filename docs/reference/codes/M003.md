# M003: a type that no record declares

A type is a truth, a number, a tuple of types, or the type of a record
that the model declares, with the fields it declares.

## Example

In the illustrative syntax of `docs/design/model.md`:

    fn weigh(s: Stone) -> kg: rational;    // error[M003]: no record `Stone`

## Fix

Declare the record, or use a type there is.
