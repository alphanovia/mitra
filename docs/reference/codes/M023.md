# M023: a correct, all or any a rule cannot write

A rule can write where functions of its part are correct, in place:
`correct(div, (6, 2))` at a point of what `div` takes, or an all or an
any of those over a set, `all x in (a: 0..10, b: 0..10): correct(div,
x)`, the point bound by the all or the any around it. A point has one
value for each argument, of its type; a set has one range for each, of
its kind; every name is bound; and only `correct`, `all`, `any` and `!`
are written so. A proposition by name is written by its path instead.

## Example

In the illustrative syntax of `docs/design/model.md`:

    subject calc {
        fn div(a: integer, b: integer) -> q: integer;
        rule everywhere: div::spec |- all x in (a: 0..10): correct(div, x);   // error[M023]: one range, two arguments
    }

## Fix

Give a point or a set that fits what the function takes, and bind each
name the propositions use.
