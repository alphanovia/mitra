# X010: a value known in part, where only what is not known could tell

A measurement gives a record known in part, `Location { depth: 2, .. }`
(finding 2), and the model reads a field it does not give, or compares
it with a value that differs only where it is not known. Explain takes
nothing there: neither for nor against.

## Example

    fn first_is(l: Location, m: Location) -> same: bool { l.first == m.first }
    measure location::first_is (Location { depth: 3, .. }, Location { depth: 3, .. }) -> true by "test:first";
    // finding[X010]: at (…), `location::first_is` reads `Location::first`, which this measurement does not know

## Fix

Give the field in the measurement, if it can be written, or measure a
function that reads only what is known.
