# X011: a measured value outside the range of its type

A measurement gives a value, input or output, outside the range type the
model declares (`a: 0..=9`). The model says nothing there, and the system
went there: a drift between the model and the code, or a measurement
taken wrong. When the system was seen to give it, explain takes that the
function is not correct at that point, by its ties, so blame lists both
the measurement and the ties as suspects. A test that expected such a
value and failed takes nothing.

An example row outside a range is another thing: the model contradicting
itself, the error M026.

## Example

    fn div(a: 0..=9, b: 1..=9) -> q: 0..=9 { a / b } at "src/lib.rs/div"
    measure calc::div (12, 2) -> 6 by "test:big";
    // finding[X011]: at (12, 2), `a` = 12 lies outside its range 0..=9: the system and the model disagree there, a drift between them or a measurement taken wrong
    // blame: drop measurements::0, or drop calc::div at src/lib.rs/div

## Fix

Widen the range if the system is meant to go there; fix the code if it
is not; or drop the measurement if it was taken wrong.
