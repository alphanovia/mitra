# P015: a `mitra.toml` Mitra cannot read

`mitra.toml`, at the project's root, gives each layer its settings, a
section each, by the names the code gives them. Mitra reads all of it:
a section, a key or a value it does not take is this error, where it is,
and nothing runs.

## Example

    [agree]
    pionts = 100
    # error[P015]: no setting `pionts` in `[agree]`: it has `points`, `splits`, `length` and `height`

    [numbers]
    prior_weight = 2
    # error[P015]: `numbers.prior_weight` takes a number above 0, with its point (`2.0`), not `2`

## Fix

Write the setting by its name, in its section (see
[8. The commands](../8-commands.md#mitratoml)). A count is a whole
number; a weight is written with its point: no number becomes another,
as in a model. Cargo stops on a `Cargo.toml` key it does not know in
the same way for `[package]`.
