# P016: a value `;` drops that is not `()`

In a block, `e;` runs `e` and drops what it gives. Only `()` is
dropped: a call made for what it does, such as writing to the
environment. Any other value dropped is a value the model computes and
never reads, most often a mistake.

Rust warns for some types (`#[must_use]`, `Result`); Mitra refuses every
type but `()`, since a model has no other reason to compute a value.

## Example

    fn f(x: integer) -> y: integer { x + 1; x }
    // error[P016]: `;` drops what this gives, of type `integer`: only
    // `()` is dropped, as a call made for what it does; name it with
    // `let x = …;` to use it

## Fix

Use the value, `let z = x + 1; z`, or take it out.
