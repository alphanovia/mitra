# X005: an input nothing measured reads

A measurement gives an input that none of its outputs reads: not an
argument of a measured function, and not what a function it calls gave.

## Example

    fn square(h: rational) -> s: rational { h * h }
    // measured: square at (5.0) gave 25.0, with sun::light::w = 2.0
    // finding[X005]: `sun::light::w` is given, and nothing this
    // measurement measures reads it

## Fix

Drop the input, or measure what reads it.
