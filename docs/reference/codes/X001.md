# X001: a measurement nothing in the model says what to expect of

A measurement saw a function give a value, and the model says nothing of
what it should give there: no body, no example at that point, no claim.
It is an observation, and nothing in the measurement reads it, so
Mitra can do nothing with it.

## Example

    fn noise(a: integer) -> n: integer at "src/stone.rs/noise";
    // measured: stone::noise at (1) gave 5
    // finding[X001]: `stone::noise` gave 5 at (1): nothing in the model
    // says what it should give there, and nothing measured reads it

## Fix

Say what it should give: a claim, an example (hint X007 offers the
values seen), or a body. Or give the value as an input of an end-to-end
measurement whose output reads it.
