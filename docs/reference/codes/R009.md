# R009: a test binary that stopped before its result

A test binary of the `cargo test` report began (`Running tests/x.rs`)
and gave no `test result:` line: it crashed, overflowed its stack or
was killed. The tests it reported before stopping are read; the ones
after did not run, or ran unseen, and measure nothing.

## Example

         Running tests/simulation.rs (target/debug/deps/simulation-1a2b)
    running 40 tests
    thread 'a_thousand_levels_of_calls' has overflowed its stack
    // finding[R009]: the test binary `tests/simulation.rs` stopped
    // before its result: its tests after the last one reported did not
    // run, or ran unseen

## Fix

Run that binary alone (`cargo test --test simulation`) to see why, and
fix the crash; tests that measure through it count again once it ends.
