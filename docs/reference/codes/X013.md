# X013: an all or an any over a set no point is in

A set's ends are fine, but its `where` leaves no point: `(a: 0..3) where
a > 5`. An `all` over it would be true with nothing to read, and an `any`
false. Explain lists the points of a set small enough (`[explain] cases`)
and, finding none, says so and gives the all or the any nothing from its
points: it stays unsupported, never explained by no evidence. A range
that is empty by its ends alone is the error [M034](M034.md).

## Example

    rule r: f::c |- all x in (a: 0..3) where a > 5: correct(f, x);
    // finding[X013]: `all x in (a: 0..3) where 5 < a: correct(s::f, x)`: no point is in the set (a: 0..3) where 5 < a: the all would be true with no point to read, so it is given nothing from its points
    //  --> s::f::r

## Fix

Widen the range or loosen the condition so the set holds the points you
meant; if no point is meant, drop the rule.
