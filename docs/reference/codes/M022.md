# M022: a model example not of its types, or missing an input

Each value of an example of the model is of the type of what it names.
And the model can compute each output: every argument of its function
is given as an input. So is every argument of a function with no body
whose value is given, so that the value is said at a point.

## Example

In the illustrative syntax of `docs/design/model.md`:

    examples {
        () -> stone::speed::v = 98.1,              // error[M022]: `stone::speed::h` is not given
        (stone::speed::h = true) -> stone::speed::v = 0.0,   // error[M022]: not of its type
    }

A `given` names a function with no body, by its whole path, with
arguments and a result of its types.

    examples {
        given Sun::light() -> true when Stone::heat(5.0) then 10.0
        // error[M022]: `Sun::light() -> true` in `given` is not what a function
        // with no body of the model gives, by its whole path, as it takes and gives
    }

## Fix

Give a value of the right type for each argument of each function the
example reads.
