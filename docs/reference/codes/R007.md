# R007: a measurement through no tie

A measurement says what a function of the real system did: it reads the function through its tie (`docs/design/model.md`, choice 8). The function has none, in the model or in the code.

## Example

    measure calc::div (6, 2) -> 3 by "human:ana";      // finding[R007] when div has no `at`

## Fix

Tie the function: `at "src/lib.rs/div"` in the model, or `// mitra: implements calc::div` above the code.
