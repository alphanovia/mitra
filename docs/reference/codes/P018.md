# P018: a route binding a name it reads nowhere

A route form binds a name in a call pattern, and nothing else reads it:
not the other pattern of `only after`, not the condition of `always`.
It says no more than `_`, and a typo would pass silently.

## Example

    claim once_each: never Tool::call(t, _);
    // error[P018]: the route binds `t`, and nothing else reads it

## Fix

Write `_`, or name it in both patterns to say the two values are one:
`Tool::call(t, _) only after Policy::allow(t, _, _, _, _) -> Decision::Run`.
