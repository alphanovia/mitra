# R008: a review seeing a test that did not pass

A review written `seeing "test:name"` says its voice holds it seeing that
test pass. It counts only while the test passes: here the test failed,
was ignored, is not in the report, or the name is no `test:name`. The
review is dropped until the test passes again. A review saying an
ensure holds, seeing a test that failed, also counts that test against
the ensure, as a test tied to it (X015): its voice said the test shows
it.

## Example

    review codes::documented holds by "human:ana" seeing "test:every_code_has_a_page";
    // the report has `test every_code_has_a_page ... FAILED`
    // finding[R008]: the test `every_code_has_a_page` failed: the review of
    // `codes::documented` by `human:ana` counts only while it passes; it
    // counts against `codes::documented`

## Fix

Make the test pass, or review again: the piece may no longer hold.
