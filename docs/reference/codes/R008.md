# R008: a review seeing a test that did not pass

A review written `seeing "test:name"` says its voice holds it seeing that
test pass. It counts only while the test passes: here the test failed,
was ignored, is not in the report, or the name is no `test:name`. The
review is dropped until the test passes again.

## Example

    review assistant::Harness::answers holds by "human:ana" seeing "test:answers_end_to_end";
    // the report has `test answers_end_to_end ... FAILED`
    // finding[R008]: the test `answers_end_to_end` failed: the review of
    // `assistant::Harness::answers` by `human:ana` counts only while it passes

## Fix

Make the test pass, or review again: the piece may no longer hold.
