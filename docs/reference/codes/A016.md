# A016: an example whose run reaches a budget

An example is one run (finding 39 B). Its run reached the step or depth
budget (`[budget]` in mitra.toml) before it gave a value, so the example
fails, and says which budget. A claim that reaches a budget is unknown
instead (A007).

## Example

    fn count(n: integer) -> c: integer {
        until((k: n, s: 0), k <= 1) { (k, s + 1) }.s
    } where {
        examples { (4) -> 2 }
        // finding[A016]: example 0: fails, at n = 4, the step budget,
        // 1000000 turns of `until`, reached before the run gave a value
    }

## Fix

The loop forgets a step (here `k / 2`), or the run is meant to be that
long: raise the budget.
