# R011: a field or variant on one side of a tie only

A record tied to a Rust struct has its fields matched by name, in any
order; an enum tied to a Rust enum, its variants. A field or variant
the model has and the code does not, or the code has and the model
does not, is listed. A record that ends with `..` says the struct holds
fields the model does not state: the struct's other fields pass.

## Example

    subject Heater {
        record { target: integer, on: bool }
    }

    // mitra: implements Heater
    pub struct Heater { pub target: i64, on: bool, cache: Vec<u8> }
    // finding[R011]: field `cache` of struct `Heater` is not in the
    // model's `Heater`: model it, or end the record with `..`, the
    // fields the model does not state

## Fix

Model the field, or end the record with `..`:
`record { target: integer, on: bool, .. }`. A field renamed on one side
shows as one missing and one extra: rename it to agree.
