# M010: a tie to no part, record or function

A tie says where a part, a record or a function is in the real system. A
claim or a rule is not somewhere: it is said of what is.

## Example

In the illustrative syntax of `docs/design/model.md`:

    tie stone::drop::falls at lab/tower/stone;    // error[M010]: a claim

## Fix

Tie what the claim is of: `tie stone::drop at lab/tower/stone;`.
