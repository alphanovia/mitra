# M033: a claim `by invariant` of what is not a loop's function

`claim c: … by invariant;` shows `c` as kept by the loop that is the
function's body: true where the loop starts, kept by each turn. It needs
that loop, `xs.fold(…) { … }` or `until(…) { … }`, as the whole body.
`by invariant n` also names the turns, which end at the length of what
a `fold` folds: an `until` has no such end, and `n` must be a name of
its own.

## Example

    subject calc {
        fn f(a: integer) -> b: integer { a } where { claim c: b == a by invariant; }
        fn g(a: integer) -> b: integer { until(b: a, b <= 1) { b / 2 } } where {
            claim c: b <= n by invariant n;
        }
        fn h(xs: [integer]) -> c: integer { xs.fold(c: 0) { x -> c + 1 } } where {
            claim c: c == x by invariant x;
        }
    }
    // error[M033]: the body of `f` is no loop: `by invariant` is on a function whose body is `xs.fold(…) { … }` or `until(…) { … }`
    // error[M033]: `by invariant n` counts the turns of a `fold`; an `until` has no count to end at: write `by invariant`
    // error[M033]: `x` is already a name of `h` or of its loop: the turns take a name of their own

A claim of a record, which has no loop, is not shown by invariant.

## Fix

Drop `by invariant` where the body is no loop; write `by invariant`
alone on an `until`; give the turns a fresh name, `by invariant n`.
Dafny writes the same with `invariant` clauses on the loop.
