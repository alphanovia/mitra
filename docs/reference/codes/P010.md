# P010: a part no file of the project declares

A `use` reads a part. A part the model's file does not declare is read
from the files of the project that declare it: every `.mitra` file under
the project's root, and Mitra's own standard model, the folder `std`,
shipped in the binary. `from "path"` keeps the files and folders whose
path ends with it. A part found nowhere is no part: Mitra does not guess
one.

## Example

    subject Calc {
        use Point::norm;
    }
    // error[P010]: no part `Point`: no file of the project declares it

    use Option from "stdd";
    // error[P010]: no part `Option` from "stdd": no file or folder of the project whose path ends with "stdd" declares it

## Fix

Spell the part as declared, write it in a `.mitra` file of the project,
or give the `from` of the folder it is in. Mitra's standard model has
`Option` and `Result`: `use Option from "std";`.
