# R001: a `mitra:` comment the reader cannot read

A comment `// mitra: …` in Rust code is read by the reader (`docs/design/reader.md`): `implements a::b` or `measures a::f (6, 2) -> 3`. This one is neither, or its row does not read.

## Example

    // mitra: evidence for div given a = 6, b = 2 gives 3     // finding[R001]: main's form

## Fix

Write `// mitra: measures calc::div (6, 2) -> 3` above the test, or `// mitra: implements calc::div` above the function.
