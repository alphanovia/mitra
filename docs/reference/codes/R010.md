# R010: a test Mitra could not read in the report

Mitra reads every test a `cargo test` report gives, from every binary:
unit tests in `src/`, `tests/`, examples, benches and doc tests. A
`test` line with no `ok`, `FAILED` or `ignored` after ` ... ` cannot be
read: the test's own output came between its name and its result, or
the line has a form Mitra doesn't know. A binary whose `test result:`
counts more tests than the lines Mitra read is listed too. Those tests
measure nothing and see nothing.

## Example

         Running tests/b.rs (target/debug/deps/b-1a2b)
    running 2 tests
    test one ... ok
    test two ... hello from two
    ok
    // finding[R010]: `test two ... hello from two` is a test line Mitra
    // cannot read: it gives no `ok`, `FAILED` or `ignored` after ` ... `
    test result: ok. 2 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out
    // finding[R010]: the test binary `tests/b.rs` ran 2 tests and Mitra
    // read 1: the others measure nothing and see nothing

## Fix

Keep the tests' output captured (no `--nocapture`, or
`--test-threads=1` with it), so each result follows its name on its
line; `--show-output` prints the output after the results, which Mitra
reads.
