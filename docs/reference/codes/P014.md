# P014: a part a `use` names that two folders declare

A folder is a name space: the files of one folder may each hold a piece
of a part (a part reopened), and a part of the same name in another
folder is another part. A `use` with no `from` names a part one folder
declares; when two do, Mitra does not choose.

## Example

    // memory/store.mitra and cache/store.mitra each declare `Store`.
    subject Agent {
        use Store::get;
    }
    // error[P014]: `Store` is declared in 2 folders: cache/store.mitra, memory/store.mitra; name the one you mean: `use Store from "cache/store";`

## Fix

Name the one you mean with `from`, the end of its path:
`use Store::get from "memory";` or `use Store::get from "memory/store";`.
As Go names a package by its folder, `import "memory/store"`.
