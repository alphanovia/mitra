# V006: a measurement missing an input, or with no output

The model computes what a measurement saw: every argument of a function
whose output it measured is given, and so is every argument of a
function with no body whose value it gave. A measurement with no output
measures nothing.

## Example

    tie stone at lab/tower;
    measurement: () -> stone::speed::v2 = 98.1     // error[V006]: `stone::speed::h` is not given

## Fix

Give each argument the model needs, and at least one output.
