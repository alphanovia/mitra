# X014: a measured value that breaks, or may break, its record's claims

Each value a measurement holds, at any depth, is read against the
claims of its record, as a value written in a row is (A012). The finding
says who gave it:

- **the world gave** it, as what a function with no body gave: the
  environment, or the claim, is wrong;
- **the test gave** it to the code: the test, or the claim, is wrong;
- **the system gave** it, or **the test expected** it: a drift between
  the model and the code, or the claim is wrong.

A record known in part (`..`) whose claim reads what is not known is
said too: the claim is not decided there.

## Example

    measurements::0: the world gave `Ruler::measure::s` holding Span { lo: 5, hi: 0 },
    which breaks record claim `Span::ordered`: the environment, or the claim, is wrong

## Fix

Find which is wrong: the system, the test, or the claim. Fix that one.
