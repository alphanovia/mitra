# A018: a given that breaks a claim of its function

An example states the world it runs in: what each function with no body
gave (`given`, or a value written as an input of a row of the model).
When a claim of that function refuses the value given, the example runs
in a world the model itself rules out (finding 39 F). Agree reads each
claim at what the given says the function took and gave; a claim that
reads an argument written `_` cannot be decided there and says nothing.

## Example

    environment Shop {
        fn price(n: integer) -> r: integer where { claim positive: r > 0; }
    }
    fn total(n: integer) -> t: integer { price(n) * 2 } where {
        examples { given Shop::price(3) -> -5 when (3) then -10 }
        // finding[A018]: example 0: `given Shop::price(3) -> -5` breaks
        // claim `Shop::price::positive`: the world given is one the model
        // rules out
    }

## Fix

The given is wrong, or the claim is: a world where the price is -5 is
either impossible, and the example should not state it, or possible,
and the claim says too much.
