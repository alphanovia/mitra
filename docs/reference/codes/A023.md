# A023: a route of an example the run breaks

An example's `then` lists a route form (`never`, `once`, `at most n`,
`only after`…), and the run of the example breaks it. The finding lists
the calls the run made, in order.

## Example

    examples { when ("hi") then 2, at most 1 Disk::write(_, _) }
    // finding[A023]: example 0: the run breaks `at most 1 Disk::write(_, _)`

## Fix

Change the body, or the route the example states.
