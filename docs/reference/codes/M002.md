# M002: a name is declared twice

Each name is declared once in its place: a part in the model, an item in
its part, a claim or a rule in its record or function, a field in its
record, and what a function takes and gives. A record's name is unique in
the whole model, since the record's type is named by it.

## Example

In the illustrative syntax of `docs/design/model.md`:

    fn drop(h: rational) -> v: rational {
        claim falls: within(v * v, 2 * 9.81 * h, 2);
        claim falls: v < 21;          // error[M002]: `falls` is declared twice
    }

## Fix

Rename one of them, or remove it.
