# A017: an example the claims of a function with no body refuse

An example is one run (finding 39 B). Its run called a function with no
body where nothing gives its value, and that function's claims keep the
run from giving what the example says, whatever value it gives there.

## Example

    environment Disk {
        fn big(n: integer) -> r: integer where { claim below: r < 0; }
    }
    fn route(n: integer) -> r: integer { if n > 10 { small(n) } else { big(n) } } where {
        examples { (3) -> 30 }
        // finding[A017]: example 0: fails: `Disk::big(3)` has no value
        // here, and the claim `Disk::big::below` keeps the run from giving 30
    }

## Fix

The body, the example or the claim is wrong. Giving the value in the
example (`given Disk::big(3) -> …`) makes the run one of a stated world.
