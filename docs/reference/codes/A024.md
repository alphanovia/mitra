# A024: a claim a symbolic run breaks

`mitra mc` ran a function with its free inputs and the results of its
functions with no body left unknown, and found a path on which a claim
is false. The finding gives the path as an example row, ready to paste.

## Example

    fn save(text: [~char]) -> n: integer {
        if Disk::exists("notes.txt") { 0 } else { let _w = Disk::write("notes.txt", text); 1 }
    } where {
        claim wrote: n == 0 || calls(Disk::write).any { c -> c.ok };
    }
    // finding[A024]: claim `wrote` is false on 1 of 3 paths; the first:
    // given Disk::exists("notes.txt") -> false, Disk::write("notes.txt", "") -> false when Notes::save("") then 1

## Fix

Read the row: the body is wrong, or a function with no body needs a
claim that rules the path out.
