# M019: a function that calls itself

No function calls itself through its body, however far: not `f` calling
`f`, nor `f` calling `g` calling `f`. With no cycle, every run of the
model ends, and a function is checked once, not at each call. Each
function on a cycle is reported.

## Example

In the illustrative syntax of `docs/model.md`:

    subject calc {
        fn even(n: Int) -> e: bool { if n == 0 { true } else { odd(n - 1) } }   // error[M019]
        fn odd(n: Int) -> o: bool { if n == 0 { false } else { even(n - 1) } }   // error[M019]
    }

## Fix

Write the repetition as an `all` over a range, or leave the function
opaque and give its examples.
