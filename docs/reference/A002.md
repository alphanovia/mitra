# A002: a body that disagrees with an example

A function's example says what it gives at a point. Its body, run at
that point, gives something else, or no value.

## Example

    fn speed(h: rational) -> v2: rational { 2.0 * 9.81 * h } where {
        examples { (5.0) -> 98.0 }    // finding[A002]: example 0: the body gives 98.1 at h = 5
    }

## Fix

Fix the body or the example.
