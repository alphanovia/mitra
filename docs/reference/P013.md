# P013: a method call on a value whose part has no such method

`t.call(x)` calls the function `call` of the part `t` is of, taking
`self` first. A part with no such function, or a value that is not of a
part (a number, a sequence), has no method of that name.

## Example

    subject Tool {
        record { name: [~char] }
        fn run(t: Tool) -> n: [~char] { t.name() }
    }
    // error[P013]: `.name(…)` calls a method, and `Tool` has no method `name`:
    // a method is a function of the value's part taking `self` first

## Fix

Read the field without parentheses, `t.name`, or declare `fn name(self) -> …` in `Tool`.
