# V001: a measurement that names no input or output

A measurement names each input and output by its function and the name
of what it takes or gives, `calc::div::a`, as an example of the model
does. An input is what a function takes, or what one with no body gave
(the world's value then); an output is what a function gives. Each is
named once on its side.

## Example

In the store's syntax (`docs/reader.md`), or a ledger built by a tool:

    inputs:  calc::div::x = 6        // error[V001]: `calc::div::x` is nothing `calc::div` takes or gives
    outputs: calc::div::a = 3        // error[V001]: what `calc::div` takes, not an output

## Fix

Name what the tied functions take and give, in their roles.
