# A003: an example that breaks a claim

A function's example, its value read as what the function gives, makes
one of the function's claims false.

## Example

    fn div(a: Int, b: Int) -> q: Int where {
        claim spec: if b == 0 { q == 0 } else { q * b <= a && a < (q + 1) * b };
        examples { (6, 2) -> 4 }      // finding[A003]: example 0 against claim `spec`
    }

## Fix

Fix the example or the claim.
