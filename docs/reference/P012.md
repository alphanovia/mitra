# P012: a part reopened as another kind

A part may be reopened, here or further on, to add to it (as Swift's
extension). It keeps its kind: a subject stays a subject, an environment
an environment.

## Example

    subject Tool { record { name: [~char] } }
    environment Tool { fn f(self) -> n: [~char] { self.name } }
    // error[P012]: `Tool` is a subject, reopened here as an environment: a part keeps its kind

## Fix

Write `subject Tool { … }` again.
