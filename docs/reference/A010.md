# A010: a comparison that holds given the claims of a function with no body

A hint. By bounds, a call of a function with no body (a value of the
world) gives any value its claims allow: `200.0 <= w` reads as `w` in
`[200, ∞)`. Nothing in the model checks those claims, so a comparison
that holds by reading them holds given them, and agree says which. A
finding that bounds decide so ends with the same `, given …`.

## Example

    environment sun {
        fn light() -> w: rational where {
            claim bright: 200.0 <= w;
        }
    }
    subject stone {
        use sun::light;
        fn heat(h: rational) -> e: rational { h * light() } where {
            claim warm: !(1.0 <= h) || 200.0 <= e;
        }
    }

    hint[A010]: claim `warm` holds, given `sun::light::bright`
     --> stone::heat

## Fix

None needed: it says what the result rests on. Measure or review
`sun::light::bright` for explain to weigh it.
