# M026: an example outside the range of its type

An example gives a value outside the range type of what the function
takes or gives. The model says nothing outside its ranges: a call there
has no value. An example of the model (`examples { … }` at the top) is
read the same way.

## Example

    fn f(a: 0..=9) -> b: 0..=9 where { examples { (12) -> 1 } }
    // error[M026]: example 0 has `a` = 12, outside its range 0..=9

## Fix

Fix the example, or widen the range if the function takes that value.
