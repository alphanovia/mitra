# M021: a model example that names no input or output

An example of the model says what the model gives across parts, as an
end-to-end test would: at these inputs, these outputs. Each is named by a
function and the name of what it takes or gives, `stone::speed::h`. An
input is what a function takes, or what one with no body gives (the
world's value there, `sun::light::w`). An output is what a function
gives. Each is named once on its side.

## Example

In the illustrative syntax of `docs/model.md`:

    examples {
        (sun::light::w = 850.0, stone::speed::h = 5.0) -> stone::speed::v = 98.1,
        (stone::speed::v = 1.0) -> stone::speed::h = 0.5,    // error[M021]: twice, an input it computes, an output it takes
    }

## Fix

Give inputs that functions take, or that functions with no body give, and
outputs that functions give.
