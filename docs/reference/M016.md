# M016: a use that names nothing of another part

A part reads another part's functions and records through a `use`, as
Rust's: `use sun::{light, Ray};` names some of them, `use sun::*;` all.
A use names another part of the model, and each name it lists is a
function or a record of that part. A part needs no use for its own.

## Example

In the illustrative syntax of `docs/model.md`:

    subject stone {
        use sun::{light, lamp};     // error[M016]: `sun::lamp` is no function or record of `sun`
        use stone::*;               // error[M016]: `use stone` names no other part
    }

## Fix

Name a part other than this one, and only its functions and records, or
use all of it with `*`.
