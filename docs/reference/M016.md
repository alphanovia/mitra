# M016: a use that names nothing of another part, or a name twice

A part reads another part's functions and records through a `use`, as
Rust's: `use sun::{light, Ray};` names some of them, `use sun::*;` all.
A use names another part of the model, and each name it lists is a
function or a record of that part, used once in the part (Rust: E0252).
A part needs no use for its own.

## Example

In the illustrative syntax of `docs/model.md`:

    subject stone {
        use sun::{light, lamp};     // error[M016]: `sun::lamp` is no function or record of `sun`
        use stone::*;               // error[M016]: `use stone` names no other part
        use sun::{};                // error[M016]: `use sun::{}` names nothing of `sun`
        use sun::light;             // error[M016]: `sun::light` is used twice
    }

## Fix

Name a part other than this one, and only its functions and records,
each once, or use all of it with `*`.
