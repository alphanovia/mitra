# A006: an example of the model the model does not give

An example of the model gives inputs across parts and states outputs.
Through calls, the model computes an output that is not the one stated,
or no value.

## Example

    examples { (sun::light::w = 2.0, stone::speed::h = 5.0) -> stone::speed::v2 = 98.1 }
    // finding[A006]: the model gives 196.2 at h = 5

## Fix

Fix the model, or the example.
