# R006: what names nothing of the model, or is not of its types

A measurement names no function of the model, or its row is not of the types the function takes and gives; a review names no claim, rule, require, ensure or tied item.

## Example

    measure calc::div (6.0, 2) -> 3 by "human:ana";    // finding[R006]: 6.0 is no Int

## Fix

Name what the model has, whole or by the last name when only one has it, with values of its types.
