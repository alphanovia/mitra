# P008: a type given the wrong type arguments

A record or an enum with type parameters is written with as many types
as it has parameters, each one its bound admits: `Option<integer>`,
`Pair<rational, bool>`. One with none takes none.

## Example

    enum Option<T> { None, Some(T) }
    fn f(x: integer) -> y: Option { None }
    // error[P008]: `Option` takes 1 type argument: `Option<T>`

## Fix

Write the types it holds, `Option<integer>`; for a bound `T: Number`, give
`integer` or `rational`.
