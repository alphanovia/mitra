# R003: a `measures` comment on no test

`// mitra: measures a::f (6, 2) -> 3` says what the `#[test]` under it measures. Here what is under it is no test.

## Example

    // mitra: measures calc::div (1, 1) -> 1     // finding[R003]
    fn helper() {}

## Fix

Put it above a `#[test]` function, or make the function a test.
