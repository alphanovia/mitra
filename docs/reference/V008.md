# V008: a measured value outside the range of its type

A measurement gives a value, input or output, outside the range type
the model declares (`a: 0..=9`). The model says nothing there, so the
measurement is refused: either the system was run outside what the model
covers, or it gave a value the model says it never gives. Both are worth
a look; the error says which value.

## Example

    fn div(a: 0..=9, b: 1..=9) -> q: 0..=9 { a / b }
    measures calc::div (12, 2) -> 6
    // error[V008]: `calc::div::a` = 12, outside its range 0..=9: the model says nothing there

## Fix

Measure inside the range, or widen the range in the model if the system
is meant to take that value.
