# B003: a diagnosis a proof by cases may outlive

Explain proves an all by its cases with one taking a point, the first
the ledger has (`docs/explain.md`, choice 5): every way to have every
point would be too many. Where another taking says the same at a point,
a diagnosis that drops the first and not the other may not resolve its
conflict: the all still follows from the other.

## Example

    // two passing tests at (6, 2), by test:a and test:b, and a failed
    // test elsewhere that contradicts the all
    // finding[B003]: a proof by cases read `correct(calc::div, (6, 2))`
    // by test:a at its point, where `correct(calc::div, (6, 2))` by
    // test:b says the same: a diagnosis that drops the first alone may
    // leave the all, and its conflict, standing

## Fix

Read such a diagnosis as a lead, not a proof: dropping it, explain
again and see whether the conflict is gone.
