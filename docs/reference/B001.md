# B001: a conflict the model's claims alone hold

Blame doubts everything but the model's claims: given the model explains
the system, they hold. Here a proposition is both true and false from
claims alone, with no evidence, rule or tie among what it rests on, so
nothing can be dropped. Today's explain never makes such a conflict: a
contradiction always rests on a rule or on evidence. The code guards
the case.

## Example

    // calc::div::spec, taken both true and false by the model alone
    // finding[B001]: `calc::div::spec` is both true and false from the
    // model's claims alone: no evidence can be blamed

## Fix

The model contradicts itself: see what `mitra check` and agree say.
