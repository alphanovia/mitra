# M014: a rule named through itself

A rule is a premise by its name, and judgement holds what it says. A rule
whose terms name it, or name a rule whose terms do, and so on, would say
what it says in terms of itself: it would mean nothing, or several things.
Each rule on the cycle is reported.

## Example

In the illustrative syntax of `docs/model.md`:

    rule slows: drop::lands, speed::slow |- drop::slow;                // error[M014]
    rule lands: drop::slows, drop::falls, speed::slow |- drop::slow;   // error[M014]

## Fix

Take one of the names out of the other's terms.
