# P004: a tuple or record whose type cannot be told

A tuple's type is the types of what it holds, and a record made with
other fields than declared has the types of what is written. Here one
of them does not check: a name not in scope, or an operation on what
it does not take.

## Example

    fn f(x: integer) -> y: integer where {
        claim c: (x, zz).0 == x;      // error[P004]: `zz` is not in scope
    }

## Fix

Make each item check where it is written: a name the function takes or
gives, `self` in a record, or one a `let` or an `all` binds around it.
