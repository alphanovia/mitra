# X007: an opaque function measured the same each time

A hint, below a finding. A function of a subject, with nothing in the
model saying what it gives, was measured, and at each point it gave one
value every time. Those values may be what it should give.

## Example

    fn noise(a: Int) -> n: Int at "src/stone.rs/noise";
    // measured twice at (1), giving 5 both times
    // hint[X007]: `stone::noise` gave one value at each point measured:
    // copy them as examples? `examples { (1) -> 5 }`

## Fix

If they are what it should give, copy them as examples. Not offered for
an environment: what the world gave is not a spec.
