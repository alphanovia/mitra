# A004: claims no value keeps together

A function's claims, all together, are false whatever it takes and
gives, by bounds: no function can keep them. Bounds read each claim on
its own ranges, so they see a claim false whatever the values, not two
that only clash on one value (`0 < v` and `v < 0` are not seen).

## Example

    fn drop(h: Real) -> v: Real where {
        claim falls = 0.0 <= v;
        claim never = 1.0 < 0.0;     // finding[A004]: no value keeps all its claims
    }

## Fix

One of the claims is wrong: drop it or fix it.
