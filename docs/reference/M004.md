# M004: a record made other than as declared

An expression, an example, an example of the model or a point a rule
writes makes a record only with the fields the record declares, and
never one whose fields are not known (an opaque record). A tuple is a
record with no name, its fields `0`, `1`, … in order.

## Example

In the illustrative syntax of `docs/model.md`:

    record Weather;                                  // opaque
    claim calm = let w = Weather { wind: 0 } in true;   // error[M004]
    rule r: calm |- correct(sense, (Weather {}));      // error[M004]: a point of an opaque record

## Fix

Make the record with its declared fields, or declare them.
