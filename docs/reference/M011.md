# M011: an empty list of an ensure

An ensure follows from any one of its lists, each held together. An empty
list would make it hold from nothing.

## Example

In the illustrative syntax of `docs/model.md`:

    ensure lands_slow = "lands slowly" from ();    // error[M011]

## Fix

Name what it follows from, or drop the list: an ensure with no list is
held only by someone taking it.
