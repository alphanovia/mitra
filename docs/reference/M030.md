# M030: a `self` that is not the first of a method of a part with a record

A method takes `self` first, written with no type: the part's own
record. A part with no `record { … }` has no value to take, and `self`
names nothing else.

## Example

    subject T {
        fn f(self) -> y: integer { 0 }
        fn g(x: integer, self) -> y: integer { x }
    }
    // error[M030]: `f` takes `self`, and `T` has no record of its own: write `record { … }` in it
    // error[M030]: `self` is taken by `g` in place 1: a method takes `self` first, and nothing else is so named

## Fix

Give `T` its record, `record { n: integer }`; take `self` first, or give
the other parameter another name.
