# P006: a `match` that misses a variant, or names one twice

A `match` gives one arm to each variant of the enum it reads, as in
Rust. An arm left out would leave a value with no result; an arm written
twice, or a `_` after every variant has its arm, is never taken.

## Example

    enum Light { Red, Amber, Green }
    fn go(l: Light) -> g: bool { match l { Green => true, Amber => false } }
    // error[P006]: `match` misses `Red`: give each an arm, or `_ =>` for the rest

## Fix

Give the missing variant its arm, or end with `_ => …` for every variant
not named. Remove an arm that is never taken.
