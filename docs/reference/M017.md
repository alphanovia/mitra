# M017: a call of no function

A call names a function of the model by its path, `sun::light()`, in a
body, a claim, or an expression written in a rule, or by its name alone
when it is its part's own or the one function of that name its uses
read. A contract's claim calls only the contract's own functions,
`Monotone::f`.

## Example

In the illustrative syntax of `docs/model.md`:

    subject stone {
        use sun::*;
        fn speed(h: Real) -> v: Real { 2.0 * h * sun::lamp() }   // error[M017]: `sun::lamp` names no function of the model
    }
    subject cloud {
        use sun::*;
        use moon::*;
        fn shade(h: Real) -> v: Real { h * light() }   // error[M017]: `light` names several functions its uses read, `moon::light`, `sun::light`: write which
    }

## Fix

Call a function the model declares, by its path, or declare it; where
two uses read one name, write the path.
