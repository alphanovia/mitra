# M024: two examples at one point that differ

A function gives one value at a point. Two of its examples at the same
point give different values: the model says two things, so it is not
well formed. (This was the finding A008, now retired.)

## Example

    fn square(h: Real) -> a: Real where {
        examples { (5.0) -> 25.0, (5.0) -> 26.0 }
        // error[M024]: examples 0 and 1 are both at (5.0), giving 25.0 and 26.0
    }

## Fix

Fix or drop one of them. The same row twice is allowed.
