# X002: a failed test whose expected value the model does not give

A test states the value it expects and says the system did not give
it. Where the model gives that same value, the function is not correct
there. Here the model gives another value, or none: what the system gave
is not known, so nothing can be said of the model.

## Example

    fn speed(h: Real) -> v2: Real { 2.0 * 9.81 * h }
    // a failed test expected 98.0 at (5.0); the model gives 98.1
    // finding[X002]: the test expected `stone::speed::v2 = 98.0` at (5.0),
    // the model gives 98.1: the system did not give the first, and whether
    // it gave the second is not known

## Fix

Make the test expect what the model gives, or record what the system
gave as a passing measurement.
