# P003: not what the language has here

The text has a word or symbol where the language has something else.
The message says what was expected and what was found.

## Example

    environment sun {
        fn light() -> w: rational }        // error[P003]: expected `;`, found `}`

Also: `-x` (only a number takes `-`: write `0 - x`), `a < b < c` (one
comparison at most, as in Rust), `examples` in a record, a keyword as a
name.

## Fix

Write what the message expects. `docs/syntax.md` has every form.
