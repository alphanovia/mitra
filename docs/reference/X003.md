# X003: a claim a measurement does not decide

A claim of the measured function, read with what the system gave, is
neither true nor false: it needs a value no one gives (an opaque
function with no example there), or it faults.

## Example

    fn lit(h: Real) -> l: Real where { claim bright: l <= light(); }
    // measured: lit at (5.0) gave 3.0, with no value of light()
    // finding[X003]: claim `bright` at (5.0): it needs what `sun::light`
    // gave, which nothing gives

## Fix

Measure the value it needs as an input of the same measurement, or give
that function an example at that point.
