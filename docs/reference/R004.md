# R004: a test that measures nothing the reader knows

A test in the `cargo test` report that ran, and that no `measures` comment the reader read names. It is evidence of nothing in the model, and listed so that it is not lost quietly.

## Example

    test tests::old ... ok               // finding[R004]

## Fix

Add `// mitra: measures …` above the test, with the row it checks, or leave it: the finding only lists it.
