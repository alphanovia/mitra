# R002: a tie comment on no item, or to nothing of the model

`// mitra: implements a::b` ties the `fn`, `struct` or `enum` under it to the part, record or function `a::b`. Here nothing is under it, or the model has no `a::b`.

## Example

    // mitra: implements calc::dvi       // finding[R002]: no function `dvi`
    pub fn div(a: u32, b: u32) -> u32 { … }

## Fix

Name a part, record or function of the model, whole, and put the comment right above the item: attributes and doc comments may come between.
