# V003: a measured value not of its type

Each value a measurement gives is of the type of what it names: a whole
number for an `Int`, a ratio for a `Real`, `true` or `false` for a
`bool`, a record of the record's fields.

## Example

    fn div(a: Int, b: Int) -> q: Int;
    measurement: calc::div::a = 6.5, calc::div::b = 2 -> calc::div::q = 3   // error[V003]

## Fix

Give each value of its type, or fix the type in the model.
