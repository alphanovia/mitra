# V003: a measured value not of its type, or of an opaque record

Each value a measurement gives is of the type of what it names: a whole
number for an `Int`, a ratio for a `Real`, `true` or `false` for a
`bool`, a record of the record's fields. No value of an opaque record
is written (`record Key;`): its fields are not known, as in an example
(M004).

## Example

    fn div(a: Int, b: Int) -> q: Int;
    measurement: calc::div::a = 6.5, calc::div::b = 2 -> calc::div::q = 3   // error[V003]
    measurement: s::mk::n = 1 -> s::mk::k = Key {}                          // error[V003]: `Key` is opaque

## Fix

Give each value of its type, or fix the type in the model; measure what
can be written of an opaque record (a function of it that gives a
number or a truth), or declare its fields.
