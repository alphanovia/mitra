# P007: an unknown variant, or one given the wrong number of values

A variant is named by its enum, `Option::Some(x)`, or alone, `Some(x)`,
when only one enum the part reads has it. It is given as many values as
it holds: `Some` holds one, `None` none.

## Example

    enum Option<T> { None, Some(T) }
    fn f(x: Int) -> y: Option<Int> { Some(x, x) }
    // error[P007]: `Some` of `Option` holds 1 value, `Some(T)`, and is given 2

## Fix

Write the variant's enum before it when two enums have it
(`Light::Red`), spell it as declared, and give it what it holds.
