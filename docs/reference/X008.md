# X008: two measurements that say one thing, by one voice and count

A measurement's takings are known by what they say: the proposition,
true or false, how many runs, and the voice. Two measurements that are
the same in all (inputs, outputs, voice) are read as one, their counts
added. Two that differ elsewhere but say one thing at one point, with
the same voice and count, give one taking: judgement cannot tell them
apart. It is read once, and blame takes it for the first measurement's.

## Example

    measure calc::div (6, 2) -> 3 by "human:ana";
    measure calc::div (6, 2) -> 3 by "human:ana";        // one, count 2: no finding
    // an end-to-end one by human:ana that also saw calc::div (6, 2) -> 3:
    // finding[X008]: it says `correct(calc::div, (6, 2))` is true, as
    // measurements::0 does, by the same voice and count: read once, and
    // blamed with measurements::0

## Fix

Write the run once, with its count, or give each measurement its own
voice (`human:ana/bench`, `human:ana/field`).
