# A008: two examples at one point that differ

A function gives one value at a point. Two of its examples are at the
same point and give different values: one of them is wrong. A simulation
reads the first.

## Example

    fn square(h: Real) -> a: Real where {
        examples { (5.0) -> 25.0, (5.0) -> 26.0 }
        // finding[A008]: example 0 against example 1: both at h = 5.0, the
        // second giving 26.0
    }

## Fix

Fix or drop one of them.
